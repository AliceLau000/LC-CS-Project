Basic Requirements: How I have met each of the requirements Evidence
BR1: Embedded System Design I have created a system with Micro:bit that once turned on, continuously collects temperature, light sensor data.
Input:
  • Digital input: Button A to calibrate my system
  • Analogue inputs: Temperature sensor and Light intensity sensor
Output:
  • Digital output: Big Fire icon / small fire icon / happy face icon on micro:bit
Calibration:
  • Once I pressed button A, it automatically continuously collects data
 Video: 0:20-0:27
BR2: Data Collection
  • I used MakeCode Datalogger to record sensor values into a microbit.csv file
  • micro:bit.csv file was then imported into the Python model
 Video: 0:28-0:56
BR3: Process Simulation
  • I simulated Wildfire risk by programming the Micro:bit to calculate a risk score
  • The system responds to higher heat and light by switching from displaying a happy face / small fire icon to displaying a big fire icon
 Video: 0:57-1:51
Advanced Requirements:
AR1: Disaster Risk Modelling
  • I developed a Python model that simulates forest fire spread
  • The model uses average temperature and light value from the Micro:bit data to determine the probability of ignition.
 Video: 1:52-3:01
AR2: What-if simulations I tested 2 scenarios:
  1. What if temperature is high and light is high? (temp = 32, light = 245)
    • Caused rapid, total forest destruction
  2. What if temperature is low and light is low? (temp = 5, light = 50)
    • Resulted in negligible spread and immediate fire burnout
 Video: 3:02-3:51
AR3: Adaptive System I created a virtual feedback loop. Python model monitors fire intensity. If risk is high, it automatically triggers an adaptive sprinkler which adjust its zone radius and fire intensity (according to watering rate) to suppress fire. Video: 3:52-4:54
