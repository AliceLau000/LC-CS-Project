4.3 A Problem that I encountered & How it was overcome

When I was making my model, I had a problem with the user interface and visualization of the forest grid in the VS Code Terminal.

Problem:
  • Initially every time the simulation updated, the model would print a brand new 20x20 grid below the previous one.
  • This causes the terminal to constantly scroll downward, making it impossible to track the fire progression visually.
  • I had to manually scroll to the bottom of the terminal to see the current status of the fire or the 'Current Fire Risk' level.

⬆️ (Output: A lot of different forest in terminal)

How I dealed with the problem:
  • I overcome this by introducing the IPython.display library.
  • I imported the clear_output function.
  • I also downloaded the Jupyter Extension on python and added “#%%” to the beginning of my code, so I could press run cell and simulation runs in an interactive window.

  • Inside the simulation loop, I added clear_output(wait=True) immediately before printing the updated grid.
