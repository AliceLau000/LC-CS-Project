5.3 How I would futher improve this project

  1. I would move away from guessing environmental variables. Now, my model assumes humidity based on temperature and light, but adding BME280 humidity sensor provides actual humidity data. This makes the ignition probability more accurate.
  2. I would change how the model handles the data. Instead of using the average values from the csv, I would make the model read through every single row. This way the simulation will react with real-time changes in the environment. This makes the forest response more dynamic.
